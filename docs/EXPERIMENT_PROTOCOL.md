# LNN+UKF 实验协议

本协议用于真实 `LNN_Lack` 数据到位后的可复现实验。所有模型使用相同的航迹级训练/验证/测试划分；验证集只用于选超参数和 EKF/UKF/CKF 的固定噪声，测试集只在模型冻结后访问一次。

| 实验 | 自变量 | 主指标 | 必须保留的诊断 |
| --- | --- | --- | --- |
| 在线协同定位 | 模型 | ATE、ADE、FDE、RMSE、MAE | NEES、NIS、95% 覆盖率、单步延迟 |
| 开环长时预测 | 预测时域 | ADE/FDE 随时域曲线、单位时间漂移 | 各模型相同初值与控制输入 |
| 稀疏量测 | 间隔、丢包率 | 定位退化率、恢复时间 | 量测掩码与有效维度 |
| 声学异常 | 离群比例/偏差 | RMSE、NIS、门控触发率 | 原始异常规则与随机种子 |
| 环境失配 | 洋流/声速/航迹类型 | 未见环境相对退化 | 训练环境与测试环境分组 |
| 少样本 | 训练航迹比例 | 误差-样本量曲线 | 固定验证/测试集 |

每一个条件应至少使用 5–10 个训练随机种子。以完整航迹为统计单位，先计算每条航迹的指标，再对 LNN+UKF 与每个比较模型做配对 bootstrap 95% CI；若进行显著性检验，采用配对 Wilcoxon 或置换检验，并对所有模型对的 p 值进行 Holm 校正。

可解释性不是“画出 τ 曲线”即完成。预注册以下四类可证伪检查：

1. τ 与速度、加速度、航向角速度、jerk、新息范数的分航迹相关和滞后相关；报告 block-bootstrap CI。
2. 在固定输入和量测下对 τ 做 0.5–1.5 倍干预，报告时间对齐重合率、空间 IoU、Fréchet 距离与末端偏离的剂量响应。
3. 对 (c_i(t)=A_{:,i}h_i(t)) 做读出闭合、节点冻结和反事实轨迹实验；任何“单元含义”应跨种子稳定。
4. 对 (AP_hA^\top)、滚动经验误差协方差、NEES/NIS 以及 Sigma 点 Monte Carlo 传播进行对比，明确可解释性映射的误差边界。
